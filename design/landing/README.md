# Дизайн лендинга — архив вариантов (июль 2026)

Материалы редизайна главной страницы (`frontend/pages/index.tsx`). В коде реализован **гибрид**;
эти файлы сохранены, чтобы можно было вернуться к исходным вариантам.

## Файлы

- **`variants-ABC.html`** — интерактивные мокапы трёх вариантов (открыть в браузере, переключение табами):
  - **А «Живой пайплайн»** — тёмный герой с анимированной схемой потока данных, светлые секции;
  - **Б «Светлый рабочий стол»** — светлый продуктовый лендинг, в герое CSS-мокап окна приложения с отчётом;
  - **В «Студия данных»** — полностью тёмный, bento-сетка, моноширинные формулы метрик.
- **`figma-variant-c-plus-components.js`** — скрипт для Figma MCP (`use_figma`, fileKey `2xf8eTtBoZSghUTN1Qlt4m`):
  одним вызовом достраивает фрейм варианта В и создаёт страницу «🧩 Компоненты» (вариант-сеты с
  текстовыми свойствами). Не выполнен из-за лимита MCP-вызовов Starter-плана Figma — запускать после сброса.
